# ClipIsland Prototype

Futuristic iOS-inspired clipboard memory app with a Dynamic Island hero UI.

## Run

Open `src/index.html` in a modern browser.

For clipboard read/write APIs, use a secure context (localhost or https).  
Example:

```powershell
cd c:\Users\nitis\Desktop\CLIP\src
python -m http.server 5500
```

Then open: `http://localhost:5500`
